# WISHLAND

NCT WISH 綜藝與影音整理（非營利粉絲自製專案）。

## 使用說明
* **類別篩選**：點擊左上角「類別」下拉選單，可快速瀏覽特定系列企劃。
* **成員篩選**：點擊「全部」、「團體」或成員名稱按鈕，可篩選出對應成員出演的影片（支援與類別交叉篩選）。
  * **分類規則**：以特定成員為主題的企劃，或單人／雙人出演的影片，才會歸類在對應的成員名稱分類中。
* **關鍵字搜尋**：於右上角搜尋框輸入標題、系列名稱或日期（格式為 `YYYY`、`YYYY-MM` 或 `YYYY-MM-DD`），即可篩選片單。
* **隨機推薦**：不知道要看哪一集時，點擊右上角「🎲 隨機看」會隨機開啟一部影片。
* **回到首頁**：點擊左上角 `WISHLAND` 標誌即可一鍵清除所有篩選條件並回到頂部。
